# raspi_server

Backend-oriented server project running on a Raspberry Pi, focused on collecting, storing and visualizing measurement data in a Linux environment.

## Purpose
The purpose of this project is to explore backend and system-level development by building a server setup that receives data from devices, stores it in a database and makes it accessible for monitoring and analysis.
The project emphasizes understanding data flow, reliability and infrastructure-level considerations.

## Features
- Data ingestion from external devices
- Time-series data storage using InfluxDB
- Data visualization with Grafana
- Secure remote access using Tailscale
- Designed to run on a Raspberry Pi (Linux)
- Script-based data collection and processing

## Technologies
- Node.js / TypeScript
- InfluxDB
- Fastify
- WebSocket
- JWT-authentication
- Grafana
- Linux (Raspberry Pi)
- Tailscale
- Git for version control

## Project status
This project is under active development. The current focus is on data collection, storage and visualization.  
API-based access and additional services may be added in later stages.
